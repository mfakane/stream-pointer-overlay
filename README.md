# Stream Pointer Overlay

OBS の Browser Source に重ねて使う、配信用のポインター・描画ツールです。
マウスに追従するポインター、クリック時の波紋、アイドル時のフェードに加え、
色ペン・マーカー・スポットライトを利用できます。

ビルドすると、実行に必要な CSS・JavaScript・標準カーソルを含む単一の HTML
ファイルが生成されます。バックエンドやアカウントは必要ありません。

## 使い方

### OBS で使う

1. `deno task build` でビルドし、生成された `public/index.html` を用意します。
2. OBS で「ブラウザ」ソースを追加し、「ローカルファイル」に `index.html`
   を指定します。幅は配信解像度に合わせ、高さは配信画面より約 80 px
   高く設定してください (1080p なら 1160 px)。
3. ソースを右クリックして「対話 (Interact)」を開き、マウスを動かします。
   ポインターの移動、クリック波紋、描画ツールの操作をここから行えます。高さを増やした
   下端は配信画面の外に出るため、ツールバーを配信画面に映さずに操作できます。

ツールバーを常に表示して Interact
から操作する場合は、設定画面の「ツールバーを常時表示」をオンにして、生成された
Custom CSS を OBS のブラウザソースへ貼り付けます。通常の表示に戻す場合は、
チェックをオフにして CSS を生成し直してください。

### 設定を変更する

`index.html` を通常のブラウザで開くと設定画面が表示されます。ポインターの種類、
サイズ、ホットスポット、フェード待機時間、クリック波紋などを調整し、生成された
Custom CSS を OBS のブラウザソースへ貼り付けてください。
波紋のサイズ、線幅、色も設定画面から変更できます。
「文字」を選ぶと表示する文字列を入力できます。初期値は絵文字の「🐱」で、
ホットスポットは中央に設定されます。

カスタム画像を使う場合は、設定画面から HTML を保存し、OBS の「ローカルファイル」
として開きます。画像パスには `file:///C:/Images/pointer.png`
のようなローカルパスを
指定してください。選択した画像はサーバーへアップロードされません。

OBS 以外でオーバーレイ表示を確認する場合は、`index.html?overlay` を開きます。
設定画面を表示する場合は、`index.html?setup` を開いてください。

## 必要なもの

- OBS Studio
- 配布物をそのまま使う場合: 対応ブラウザまたは OBS の Browser Source
- ソースからビルドする場合: [Deno 2.9 以上](https://deno.com/)

実行時に外部サービスは必要ありません。依存パッケージは Preact 10.29.8 で、
バージョンは `deno.lock` に固定されています。

## ビルド

```sh
git clone https://gitlab.com/mfakane/stream-pointer-overlay.git
cd stream-pointer-overlay
deno task build
```

ビルド結果は `public/index.html`
です。初回の依存取得にはネットワーク接続が必要ですが、 生成された HTML
は単独で利用できます。

開発中にローカルプレビューを起動するには、次を実行します。

```sh
deno task dev
```

ブラウザで <http://localhost:3000/>
を開いてください。その他のタスクは次のとおりです。

```sh
deno task check  # 型チェック
deno task test   # テスト
deno task fmt    # フォーマット
```
